Degradation ladder — the trust story (what happens when it breaks)

    

      
ai_assist
retrieval + rules + grounded rationale. Full assist.

      
stale_data
FHIR feed lagging → banner: clinician must verify vitals.

      
rules_fallback
vector store / LLM down → rule-only ESI, still safe.

      
off
assistant silent → pure human triage. No silent failure.
